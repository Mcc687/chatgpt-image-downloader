GPT 图片一键下载 2.2.0 - Windows / Chrome 安装

推荐方式：
1. 从 GitHub Releases 下载最新版本，或下载仓库的 Source code (zip)。
2. 解压到固定文件夹；安装后不要移动该文件夹。
3. 在 Chrome 地址栏打开 chrome://extensions。
4. 开启右上角“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择能直接看到 manifest.json 的文件夹。
6. 双击 install-native-helper.cmd。
7. 回到扩展程序页面，点击“GPT 图片一键下载”卡片上的重新加载按钮。
8. 刷新 ChatGPT 页面。

使用：
鼠标悬停到 GPT 生成图片组，点击右上角绿色下载按钮；每次选择保存文件夹后，图片会按 1、2、3……连续命名。

更新：
把新版文件覆盖到原来的固定文件夹，再重新加载扩展并刷新 ChatGPT。若移动了文件夹、重新加载成了另一个扩展 ID，需再次运行 install-native-helper.cmd。

注意：
必须先加载扩展，再运行安装脚本，否则脚本无法自动识别 Chrome 分配的扩展 ID。
