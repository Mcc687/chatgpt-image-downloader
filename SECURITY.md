# Security policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Prefer GitHub's private vulnerability reporting for this repository. If that is unavailable, open a minimal issue asking for a private contact channel and do not include credentials, tokens, private image URLs, or a working exploit in the public issue.

The extension should never collect passwords, cookies, browser profiles, or ChatGPT conversation text. Its native host is limited to selecting a local folder and writing image bytes supplied by the extension.
